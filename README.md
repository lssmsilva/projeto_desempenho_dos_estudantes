# 📘 Projeto de Estatística — Students Performance

Este repositório contém as análises desenvolvidas durante os módulos de **Estatística I e II** da pós-graduação em Engenharia e Análise de Dados.  O estudo utiliza o dataset **Students Performance**, composto por 1.000 estudantes com informações pessoais, socioeconômicas e desempenho acadêmico. 

O notebook principal realiza cálculos de probabilidade, probabilidade condicional, **Teorema de Bayes**, variáveis aleatórias e visualizações estatísticas.

---

## 📁 Estrutura do Repositório
```
data/
└── StudentsPerformance.csv       # Dataset (adição manual)

notebooks/
└── estatistica_students_performance.ipynb   # Notebook principal

README.md
requirements.txt
```
---

## 🎯 Objetivos do Projeto
- Explorar e compreender a estrutura do dataset Students Performance.
- Aplicar conceitos fundamentais de:
  - Probabilidade simples
  - Probabilidade condicional
  - Teorema de Bayes
  - Variáveis aleatórias e estatística descritiva
- Criar visualizações comparativas entre grupos.

---

## ▶️ Como Executar
1. Instale as dependências:
```bash
pip install -r requirements.txt
```
2. Certifique-se de que o dataset está em:
```
data/StudentsPerformance.csv
```
3. Abra o notebook:
```bash
jupyter notebook notebooks/estatistica_students_performance.ipynb
```
