# Projeto-de-Estat-stica-Students-Performance
Repositório com análises dos módulos de Estatística I e II da pós-graduação em Engenharia e Análise de Dados. O estudo usa o dataset Students Performance, com 1.000 alunos e dados pessoais, socioeconômicos e notas em Matemática, Leitura e Escrita. O notebook aplica probabilidade, Bayes, variáveis aleatórias e visualizações.
